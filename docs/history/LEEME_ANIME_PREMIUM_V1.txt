INSTALAR EN WINDOWS
1. Abre ÚNICAMENTE esta carpeta nueva en VS Code.
2. Usa Node.js >=22.13.0 y pnpm 11.25.0, como la fuente recibida.
3. En la terminal PowerShell de esta carpeta:

   Copy-Item .env.example .env.local
   pnpm install --frozen-lockfile
   pnpm dev

4. Abre http://localhost:5174/anime

La versión anterior puede seguir en 5173. El puerto 5174 separa los datos del
navegador. La selección Premium usa además una clave distinta de la original.
.env.local creado desde el ejemplo solo contiene configuración de revisión.
No copies el .env.local de producción a esta carpeta por rutina.

ORDEN DE PRODUCTOS
La regla se aplica solamente en Anime Shop y sus líneas. Primero se filtra la
colección y luego se ordena: 5 dobles confirmadas en la lista visual existente,
1 referencia de la lista restante, y repetir. Al agotarse las dobles se muestran
las demás. La secuencia continúa al cargar más; no se reinicia cada pantalla.
La lista restante puede incluir referencias pendientes de verificar; no se les
muestra una etiqueta de estampado sencillo sin evidencia. No hay cifras de ventas
para llamar a la selección "más vendidas"; se usa una selección editorial.
Anime comienza con Gojo 483, Hellsing 125, Luffy 491, Killua 504 y ANBU 147.
